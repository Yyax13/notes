Following the division rule of the [[The Exponentiation Rules|Exponentiation Rules]]

$$
\frac{x^a}{x^a} = x^{a - a} = x^0
$$

As we can see, two numbers with the same base divided by each other, them both with the same exponent, result in $0$, and following the basics of division, any number divided by itself results in $1$, so

$$
\frac{x^a}{x^a} = 1
$$

This means that the equality of this division will be the same in the simplified case $x^0$

$$
x^0 = 1
$$
$$\frac{x^a}{x^a} = x^0 = 1$$
