
The sexagesimal counting system uses base 60 to count.

---

## Uses

Commonly used to:
- Measure time: One hour is 60 minutes, which is 60 seconds (we used to use [[Thirds (Tertias)]], *the 60th part of seconds*)
- Calculate angles: From 0 to 360
